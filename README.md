# outpost-pepys

🌐 **ENGLISH / ESPAÑOL**

## Description / Descripción

**EN:**  
A web application and toolkit for generating collectible token artwork.  
Seamlessly merge various core templates and environment layers, inspect compositions live, and package your token series with attributes for marketplaces like Rarible.  
Built with Vue and TypeScript.

**ES:**  
Aplicación web y toolkit para la generación de arte de tokens coleccionables.  
Fusiona fácilmente diferentes plantillas base y capas de entorno, inspecciona el resultado en tiempo real y empaqueta tu serie de tokens con atributos listos para mercados como Rarible.  
Desarrollado con Vue y TypeScript.

## Features / Características

## Getting Started / Primeros pasos

1. **Clone this repository / Clona este repositorio:**
   ```bash
   git clone https://github.com/forgedev/outpost-pepys.git
   cd outpost-pepys
   ```

2. **Install dependencies / Instala dependencias:**
   ```bash
   npm install
   ```

3. **Start the development server / Inicia el servidor de desarrollo:**
   ```bash
   npm run serve
   ```

4. **Open / Abre:** [http://localhost:8080](http://localhost:8080)
